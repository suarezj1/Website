Overview

This project explores how unauthorized access attempts can be observed and analyzed within a controlled virtual environment. The lab was designed to capture system activity and network traffic while keeping the testing environment isolated.

The project combined virtualization, Linux system administration, network monitoring, packet capture, and log analysis to examine how connection attempts appear at both the system and network level.

Core Question:

What can captured system logs and network traffic reveal about unauthorized connection attempts?

Rather than limiting analysis to whether each connection attempt succeeded or failed, the project investigated the activity generated during such attempts, focusing on its identifiability through system logs and captured network traffic.

Lab Architecture

The project was built inside a controlled virtual environment to observe connection activity without exposing the host system or personal network. Separate virtual machines were used to isolate testing activity and monitor how network and system events appeared during simulated access attempts.
